# Modern Robotics Assignment & Projects
In my undergradute program, I only learned about configuration and kinematics of robot which I find it is not enough. After wondering around the internet, I found a book named "Modern Robotics: Mechanics, Planning and Control" associated with a [Coursera course](https://www.coursera.org/programs/open-access-guyana-ngeor/specializations/modernrobotics?source=search). This book will take you through the fundamentals problems related to robotic system including dynamics, kinematics, motion planning, control, odometry,... 

A digital copy of the book can be found at: [Modern Robotics original page](https://hades.mech.northwestern.edu/index.php/Modern_Robotics). 

---
# What are in this repository? 
This repo is used to log my completed projects and assignments which are related to the book as well as the online course.
- A* algorithm: Optimal path planning
- RRT algorithm: Obstacles-avoidance trajectory planning
- Grasp form closer: Check stability of grasping based on contact 
- Grasp force closer: Check stability of grasping based on contact and force
- Line Follower Robot project
- Robot dynamic project: Simulate behavior of robot based on its dynamics
- Capstone project: A mobile manipulator doing pick-and-place task
